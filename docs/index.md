## Overview

Filament Switch Panel is a lightweight Laravel package that integrates seamlessly with the Filament admin framework. It provides a user-friendly interface for administrators to switch between different panels without leaving the admin interface.

### Key Features

- **Multi-Panel Support**: Switch between multiple Filament panels with ease
- **User Authorization**: Built-in authorization checks for panel access
- **Customizable UI**: Multiple display modes (dropdown, modal, slide-over)
- **Configuration Options**: Extensive configuration options for flexibility
- **Version Compatibility**: Supports both Filament v3 and v4
- **Zero Configuration**: Works out of the box with sensible defaults
- **Fluent API**: Easy-to-use fluent interface for configuration

### Requirements

- PHP 8.1 or higher
- Laravel 8.1 or higher
- Filament 3.x or 4.x
